# Бот-каталог косметики для Telegram

## Запуск

1. В Telegram откройте **@BotFather** → `/newbot` → получите токен.
2. Скопируйте `.env.example` в `.env` и вставьте туда токен.
3. Установите зависимости и запустите:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
4. Откройте своего бота в Telegram и нажмите **Start**.

Бот работает, пока запущен `bot.py`. Чтобы он работал круглосуточно, его нужно
разместить на сервере (VPS, Railway, PythonAnywhere и т. п.).

## Админ-панель — команда /admin

Удобнее всего менять каталог прямо в Telegram: отправьте боту **/admin**.

- **📦 Товары** — изменить любое поле, фото (просто пришлите картинку), разделы,
  кнопки покупки, порядок в списке; добавить или удалить товар.
- **🗂 Разделы** — кнопки главного меню: добавить, переименовать, поменять порядок, удалить.
- **💬 Приветствие / ℹ️ О магазине** — тексты; жирный и курсив из Telegram сохраняются.
- **🔗 Кнопки в «О магазине»** — ссылки на Instagram, Ozon и т. п.
- **/cancel** — отменить ввод.

Доступ есть только у Telegram ID из строки `ADMIN_IDS` в `.env` (несколько — через запятую).
ID человека, который отправил боту /admin без доступа, записывается в журнал бота.
После изменения `.env` бота нужно перезапустить.

Покупатели не могут писать в чат: их сообщения бот сразу удаляет и подсказывает
пользоваться кнопками. Писать могут только админы.

Перед каждым сохранением прошлая версия каталога копируется в `products.backup.json` —
если что-то случайно удалили, её можно вернуть.

## Как редактировать товары вручную — файл `products.json`

Правки видны сразу, перезапускать бота не нужно.

- `shop` — приветствие, текст «О магазине» и кнопки-ссылки `links` (Ozon, Instagram…).
- `categories` — категории: `id` (латиницей, без пробелов) и `title` (название на кнопке).
- `products` — товары:

| Поле | Что это | Обязательно |
|---|---|---|
| `id` | короткий уникальный код товара латиницей | да |
| `category` | `id` категории или список: `["face", "body"]` | да |
| `name` | короткое название (оно же на кнопке) | да |
| `price` | цена, например `"705 ₽"` | да |
| `brand`, `volume` | бренд, объём | нет |
| `description` | описание | нет |
| `composition` | состав | нет |
| `how_to_use` | способ применения | нет |
| `where_to_buy` | текст «Где купить» | нет |
| `photo` | файл из папки `photos/` (например `"photos/scrub.jpg"`) или прямая ссылка | нет |
| `buy_links` | кнопки-ссылки: `{"title": "...", "url": "..."}` | нет |

**Фото:** проще всего положить .jpg в папку `photos/` и указать путь к нему.
Картинки с Ozon по ссылке не подойдут: Ozon отдаёт их в формате WebP.

**Цены** в файле не обновляются сами — при изменении цены на Ozon поправьте её здесь.

Текст карточки товара с фото должен быть не длиннее ~1000 символов. Если длиннее,
бот покажет товар без фото.
